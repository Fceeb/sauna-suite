# Security

## Supported Versions

Sauna Suite is in early development. Security reports should target the latest
commit on `main` until tagged releases begin.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by opening a GitHub security
advisory or contacting the maintainer through the repository owner profile.

Do not open public issues for sensitive security reports.

## Safety-Sensitive Features

Future sauna control features may affect real equipment. They must be designed,
reviewed and documented separately before implementation.
