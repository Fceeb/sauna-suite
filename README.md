# 🔥 Sauna Suite

Sauna Suite is a modular Home Assistant ecosystem for intelligent sauna automation.

It combines a modern Lovelace dashboard, intelligent heating prediction, battery & PV optimization, session analytics, RGB lighting, media notifications and optional full sauna control into one seamless experience.

---

## Features

- 🌡 Multi-zone temperature monitoring
- 🔥 Intelligent heating prediction
- ⚡ Battery & PV optimization
- 📈 Session analytics
- 📅 Smart scheduling
- 💡 RGB lighting integration
- 🔊 HomePod / Media Player notifications
- 🧠 Learning ETA calculation
- 🎛 Optional Home Assistant temperature control
- 📦 HACS ready
